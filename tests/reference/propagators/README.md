# Propagator reference inputs

The eight numbered text files extract the 69-character TLE lines and the first seven
columns (minutes, TEME km, km/s) from `sgp4/SGP4-VER.TLE` and `sgp4/tcppver.out` at
[python-sgp4 8126f773923c2902719d45aab8bdb5cce86cf39d](https://github.com/brandon-rhodes/python-sgp4/tree/8126f773923c2902719d45aab8bdb5cce86cf39d).
No values or checksums were recomputed. License: the MIT notice in
`modules/providers/sgp4/third_party/LICENSE`. The original verification suite accompanies
[Vallado et al., AIAA 2006-6753](https://celestrak.org/publications/AIAA/2006-6753/).

`j4.txt` is generated by `generate_j4.py`, using mpmath 1.3.0 at 60 decimal digits.
Run it from the repository root. The independent reference transcription follows
[SatelliteToolboxPropagators.jl 2fded936bbc911c4ecd3a48c2b9fdae7cc9c8e5e](https://github.com/JuliaSpace/SatelliteToolboxPropagators.jl/blob/2fded936bbc911c4ecd3a48c2b9fdae7cc9c8e5e/src/propagators/j4.jl),
under the MIT notice at `modules/providers/spice/third_party/SatelliteToolbox-LICENSE.txt`.
It solves eccentric anomaly at high precision and obtains velocity by differentiation,
independently of CSPICE and the production rotation-cross-product implementation.
Columns are elapsed TAI seconds, GCRF metres and metres/second; epoch is `Epoch(0)`.
Input: a=7000000 m, e=.01, i=98.5°, Ω=25°, ω=70°, M=10°; EGM2008 constants.
This is a formula/transcription regression, not a direct STK comparison.
