# 地面站可见性与卫星传感器

## 桌面工作流

1. 在地面站属性中设置 WGS84 地面位置、离地高度与最低仰角（默认 0°，允许 −90–90°，仍受当地地面遮挡约束）。
2. 卫星右键 → **插入传感器**。支持圆锥、复合圆锥、矩形和自定义视场，可设置对地心或跟踪地面站的基准指向、局部 X/Y/Z 三轴偏转及显示样式。属性应用后生效，关闭不提交草稿。
3. 地面站、卫星或传感器右键 → **可见性分析**。报告左侧明确列出地面站和卫星／传感器两个对象；右键对象预先选中，对端默认首个可用对象。点击对象字段打开统一的“对象选择窗口”，按名称、路径或 ID 搜索，按适用类型选择；传感器显示在父卫星下方。
4. **可见时段 · Access** 输出起止、持续时间、最大仰角、最近距离及各自历元。上方摘要显示次数、总可见时长、最长和平均过境；最短时长可在摘要提示中查看。起止后的 `*` 表示被分析区间截断，悬停说明。双击仰角／距离跳转到相应极值时刻，双击起止跳转对应边界；右键菜单提供四个关键时刻。完整字段（含截断标记、极值历元）保留在 CSV。生成后仍同步场景时间轴和二维地图。
6. 搜索方式可选 **极值辅助搜索**（默认）和 **固定步长**；最大检查间隔默认 60 s，时间容差默认 1 ms。设置保存在项目报告模板中。摘要随结果保存于内存，切换显示单位、缩放或调整窗口宽度不会重新传播；窄窗口的四张摘要卡片改为两列。
5. **AER · 方位 / 仰角 / 距离** 输出全部采样时刻的 AER、距离变化率、可见标志和传感器离轴角。曲线默认显示仰角，可切换字段、缩放、跳转时刻和导出 PNG；两类表格均可导出 CSV。

传感器属性页显示所属卫星与圆锥截面示意，修改半角时同步显示全视场角；示意不代表地面覆盖范围。指向方式直接切换，只有跟踪模式显示目标地面站；临时切换模式保留目标草稿，目标缺失时要求重新选择，不自动改绑其他站点。窄侧栏可滚动查看设置，底部操作始终可见；插入、应用与取消的含义分别标明，无效输入在页内提示。

跟踪目标也通过“对象选择窗口”选择，仅列出地面站。对象多时在固定高度的列表中搜索和滚动；同名对象可通过路径与 ID 区分。只有确定后才更新字段，取消保留原绑定，随后仍须应用传感器属性才会修改场景。

“姿态偏转”按 X、Y、Z 顺序输入。X/Y 改变实际视轴，Z 绕最终视轴调整视场朝向；标题旁的“偏转归零”只重置这三个角度的草稿，仍须应用。坐标轴与右手规则的详细说明收在信息提示中。切换基准模式、调整面板宽度和切换角度单位均保留偏转。跟踪站点始终决定基准方向，但偏转后的视场可能不包含该站点；AER 离轴角、可见性和区域覆盖使用偏转后的实际视轴。

三轴示意图随角度草稿即时变化，不需要应用或重新传播。虚线为基准坐标轴，彩色实线为偏转后的局部 X/Y/Z；Z 为实际视轴，方框只显示绕视轴的朝向，不表示实际视场形状或地面覆盖。无效角度显示纠错提示，不继续展示旧方向。宽面板将图示与输入并排，窄面板上下排列；示意图使用 Qt 矢量绘制，按 DPI 重绘。

传感器应用或复制成功后，对象浏览器自动选中新节点并展开其父级；编辑和重命名保留传感器的选择。更新时重新应用当前搜索条件，匹配子传感器时显示其父卫星；不匹配的对象继续隐藏。其他卫星的展开／折叠状态保持不变，失败或取消不替换当前对象树。

生成任一 Access 报告后，二维地图在该对象对满足约束时显示青绿色虚线。连线只是对象地面投影间的关联提示，不代表地面通信路径。传感器默认显示二维地面投影及三维半透明视场，与场景时间联动；不需要先生成报告。暂未提供三维可见连线。

修改计算输入或打开项目后清除时间轴区间及地图关联，须重新生成。后台报告捕获不可变输入；完成后如果已过期，保留带过期提示的结果供查看，不把它发布到当前场景联动。模板保留稳定 ID；对象被删除时明确报错，不自动替换为父卫星或其他站点。

## 计算契约

- `core::observe_ground_target` 接收同一历元的 Earth/ITRF 目标状态和固定 WGS84 站点位置。完整状态变换保留地球自转速度项，支持二体、J2、J4、HPOP 与原生 TEME 的 SGP4。
- 方位角在当地大地 ENU 坐标系中由北向东，范围 `[0, 2π)`；仰角相对当地水平面；斜距单位 m，距离变化率为相对速度沿视线的投影（远离为正，m/s）。天顶／天底的方位未定义时返回空值，CSV 留空、曲线断开；不以零冒充北向。
- 可见性同时检查站点最低仰角、当地地面椭球的线段遮挡，以及所选传感器视场。地面椭球经过输入的地面点并保持 WGS84 法线；设备位置另加离地高度，负椭球高站点不会因此永久被挡住。模型及高度语义见[地面站](ground_stations.md)。显示时抬高标记不改变分析。
- `ProjectSensor` 的位置等于父卫星位置。圆锥外半角范围 `(0, π)`，复合圆锥内半角须小于外半角；钟角支持跨零区间，0–360° 表示完整圆周。矩形水平、垂直半角均在 `(0, π/2)`，由 XZ/YZ 平面上的四条边界定义。Nadir 明确定义为对地心，Targeted 为同一历元指向指定站点的理想跟踪。没有姿态机动、转速上限、安装位置平移、地形、折射、光行时、天线增益和通信链路预算。
- 固定模式使用 `core::find_access_intervals`，保留固定网格和二分边界细化。默认增强模式使用 `core::find_constraint_intervals`，在每个最大检查区间对可见性有符号余量分别做有界黄金分割最大／最小搜索，再对发现的符号变化二分细化。目标是发现网格之间的短窗口及短不可见间隙；所有候选均重新求值物理轨道和约束，绝不插值显示缓存或约束值。
- 增强模式要求检查间隔能够分辨不同峰谷（局部单峰波瓣）；不是任意振荡、不连续函数的完备搜索，也不是 STK 私有自适应算法的复刻。必须通过缩小最大检查间隔核对收敛；小于时间容差的事件不保证可分辨。固定模式仍可能漏掉比步长短的窗口。
- 时间容差为正且不超过检查间隔；边界在可见一侧，误差指已发现事件的时间括区宽度。孤立零时长接触不输出为过境。最多 200000 个粗检查节点、每次过境分析最多 2000000 次不同历元求值，超限明确报错，不返回部分结果。回调异常和取消同样不会发布部分结果。
- `runtime::calculate_access_passes` 由报告和 Analysis 共用。每个可见区间内按检查间隔分段，用 `core::find_access_extremum` 连续搜索最大仰角与最小斜距，显式比较两端；它们可能发生在不同历元。同值平坦区间返回最早遇到的最优历元；非唯一极值不承诺唯一时刻。极值单位为 rad / m，时间为精确 TAI 纳秒。
- 汇总按返回的正时长窗口计算 count、total、mean、shortest、longest，包括截断窗口的可见部分；空结果各统计数值为 0，UI 的平均和最长显示 `—`。因此这些统计是分析区间内的统计，不冒充完整轨道过境长度。
- `runtime::AccessSession` 拥有项目和时间／EOP／Frame Provider 的快照。必须显式提供与项目记录一致的数据，越界历元报错。结果标识为 `geometric-access-wgs84-local-ground-v2`，记录项目输入、数据锁和时间数据哈希。搜索步长等查询设置保存在结果定义中，不属于项目输入哈希。

## 对象与持久化

文件层 `application::Project.sensors`（Python `ProjectData.sensors`）保存独立稳定 ID、名称、父卫星 ID、完整视场参数、三轴偏转角、基准指向与目标、显示设置。ID 在卫星、地面站、传感器之间全局唯一；总上限 10000。传感器不额外产生 Scenario 的轨道 Session 或重复的卫星位置标记。显示设置不进入分析输入哈希。

复制卫星同时复制子传感器并生成新 ID；删除卫星同时删除子传感器。传感器可单独重命名、复制和删除。被 Targeted 传感器引用的站点不能直接删除，须先修改指向或删除传感器。无效父对象、目标、非有限半角和重复 ID 均在发布／保存前拒绝。

当前项目 v51 使用 GSTN v3 保存地面坐标、离地高度、最低仰角及设施元数据、必需的 SNSR v4 保存传感器，并支持报告类型 7（Access）和 8（AER）。开发阶段仅读写当前格式，不从旧文件补默认值；详见[文件布局](project_files.md)。Access 配置可保存为报告模板，计算结果仍按报告契约导出，不写入项目。

## 几何视场与显示

Core 的 `SensorGeometry` 统一验证边界并提供有符号角度余量。圆锥和矩形使用解析边界，自定义视场采用前半球内简单球面多边形；允许凹边和离轴轮廓，边缘为相邻顶点间的短大圆弧，支持 3–256 点，拒绝自交、孔洞和后半球顶点。Access、覆盖率报告均使用此几何。

基准坐标系 +Z 为对地心或跟踪站点的方向，+X 为 ITRF 速度在垂直于基准 Z 的平面上的投影，+Y=Z×X；退化时选取与 Z 最不平行的 ITRF 坐标轴。偏转采用右手规则的内禀 X → Y → Z 顺序，即列向量变换 `R = R_base Rx(tilt_x) Ry(tilt_y) Rz(roll)`：先绕局部 X，再绕转动后的 Y，最后绕转动后的 Z。最终 +Z 是实际视轴，最终 +X 是零钟角方向。Z 旋转不改变最终视轴，但影响矩形、钟角扇区和自定义视场；完整圆锥的 Z 旋转不改变覆盖。三个角均须有限；低层接口单位 rad，桌面按角度单位编辑，不通过反求欧拉角修改用户输入。

这是相对随轨道移动基准的固定角偏转，不含卫星姿态动力学、安装位置平移、转速限制或随时间变化的指向序列。零偏转保留原指向行为；二维投影、三维视场、Access、AER 和覆盖率共用同一坐标轴实现。

自定义编辑表以度输入，导入后保存解析后的点，不依赖原文件路径。支持 STK 的 ReferenceDistance/PatternData，以及显式 `InterpolateAzElPts No` 的 HalfAngleAzimuthData、AzElMaskData。文件必须重复首点闭合；角度格式没有该指令时拒绝，以免把 STK 的默认角度插值误读成大圆边。未知指令、超过 256 KiB 的文件均拒绝。

Visualization 缓存角域网格。每帧只采样已有 ITRF 显示轨迹，并用 Hermite 导数取得显示速度；不触发轨道传播。三维射线优先截在 WGS84 表面。“显示太空延伸”默认关闭，开启后才显示延伸到指定距离的未命中部分；关闭仍保留距离草稿，并沿地平线补齐截断视锥的半透明侧面，使用与落地部分相同的不透明度。开启延伸时取消这层截断面，太空面片使用设置不透明度的 25%，轮廓透明度为 0.3，突出落地视锥。开关随项目保存，Python 使用 `SensorDisplay.show_space_extension`。侧面沿每段角域边界求出全部地平线交点，分别构造落地和太空延伸面片，不把两种长度的端点直接连成斜跨地平线的面片；两端均未命中但中间穿过地球的边界段同样裁剪。延伸开关和距离仅影响三维显示，不改变二维覆盖或分析输入身份。

二维地面投影在椭球缩放空间内将角域三角形裁剪到可见地球圆盘，因而支持整个地球落入视场、部分地平线相交、中心盲区和离轴凹轮廓。透视除法前先用齐次平面限制投影坐标，再求角域边与真实圆周的交点，避免折线圆盘将边界交点投到地平线内侧。射线求交保留浮点舍入范围内的相切顶点，真正未命中的射线仍被排除。地面面片只二分超过约 3° 的最长边，避免细长三角形重复细分；日期变更线处展开经度并重复裁剪，极区补齐极点边界。地球边缘保留 128 段及精确视场交点；计算边界不使用此显示近似。

三维轮廓使用随 DPI 调整宽度的屏幕空间抗锯齿四边形；贴地线段按至多 0.5° 细分，使弦的下沉量小于显示抬升，避免线段穿入地面而断续。地平线截断侧面沿切点圆周以至多 0.5° 细分，仅抬升接地端点，避免粗面片与地球相交形成成排缺口。透明面片剔除 WGS84 内部片元，并平滑接地边缘。VSG 动态缓冲按实际需求增长，颜色转换匹配 sRGB，深度测试开启、透明面不写深度。

二维投影采用独立后台栅格缓存：拖动或缩放时重投影已有图像，越过缓存边缘时后台补齐，停止后按当前视口与 DPI 补齐细节。快速缩放仍保留相交的覆盖图及在途任务，直到新比例的图像完成，避免高倍缩放时因全图预览不可用而闪烁。缓存只保留一张 2048×1024 全图预览、一张带边距的视口图像及一个在途任务，内存不随地图放大倍数增长。填充先剔除和裁剪屏幕外面片，在双倍像素尺寸的单字节覆盖掩模中逐面片绘制，再统一平均每个 2×2 像素块并施加颜色和不透明度，避免分别混合三角形边缘留下内部细缝，也避免大型绕数路径的合并开销。临时掩模与视口尺寸成正比；外轮廓独立抗锯齿绘制。

连续向前播放保留最近完成的覆盖图，允许当前后台任务完成，再取最新位置继续绘制；中间时刻合并而不排队，也不逐帧清空缓存或取消任务。界面线程只复制落地面片、轮廓与样式；经纬度路径转换也在该后台任务内执行，被合并的中间帧不做路径转换。在可用比例下交替更新预览和视口细节，避免平移时退回长期未更新的预览。暂停后补齐当前时刻和视口。配置变化、时间跳转和循环回绕使旧修订失效，删除、隐藏传感器时立即清除缓存，过期任务不能恢复旧投影。缓存只影响显示，不参与可见性计算。经纬网格在送入虚线绘制前裁剪到可见区域，并保留相对地理坐标的虚线相位，避免高 DPI 下处理屏幕外的长线。

传感器属性参考 [STK 属性页分组](https://help.agi.com/stk/content/stk/ObjectProperties.htm)，按基本（定义、指向）、二维显示（属性）、三维显示（投影）组织。二维属性页中的颜色、填充和不透明度由二维与三维共用，三维投影页提供跳转入口；显示设置不改变可见性计算。复合圆锥按[半角、钟角](https://help.agi.com/stk/Content/stk/sn-01.htm)分组。

表单靠左上方排列，内容区最多 640 个逻辑像素，避免宽工作区把输入框和示意图拉散。宽面板使用分组侧栏，中等宽度使用页签，窄面板使用页面选择器，成对参数与示意图按实际可用宽度重排。每页独立滚动，应用、关闭和重置保持可见。调整宽度与切换页面不重建控件，保留草稿、单位、目标选择和当前页。

二维地图基准使用 `GroundMapTest.ProfileZoomedSensorPanning`；设置 `ORBELLE_SENSOR_PAN_PROFILE` 为尚不存在的输出目录后运行 `orbelle_ground_map_tests --gtest_filter=GroundMapTest.ProfileZoomedSensorPanning`。固定 1280×800 逻辑像素、12 倍缩放、30 次位移，分别检查无传感器、45° 近地圆锥和 80° 高轨圆锥；另测长拖动越过缓存边缘。每种配置还在 2 倍及 12 倍初始缩放下连续提交 48 个时刻，并穿插放大和缩小，分别记录几何投影、地图输入、绘制与后台栅格耗时。`QT_SCALE_FACTOR=1/2` 可复测不同 DPI，实际 DPR 记录在报告中。`profile.json` 的耗时只衡量 Qt 地图测试路径（包括测试抓图），不等同整机帧率或输入到屏幕的延迟；过期任务、盲区、移除、连续播放、平移与缩放后的图像一致性由普通回归用例检查。

Python 对应 `sensors.Cone`、`ComplexConic`、`Rectangular`、`Custom`，均可用于 `project.objects.sensor(field_of_view=...)` 或句柄更新。EOIR、SAR、半功率天线模型不在本轮范围内。

参数定义参考 STK [Sensor Definition](https://help.agi.com/stk/Content/stk/sn-01.htm)，空间延伸参考 [3D Projection](https://help.agi.com/stk/Content/vo/sensors-02.htm)，文件子集参考 [Custom Pattern](https://help.agi.com/stk/Content/stk/sncustom.htm)。这里复用几何概念，界面沿用 Orbelle 的属性页及资源文案。

## SDK 与 Python

公共入口：`core/propagation/access.hpp`、`runtime/access.hpp` 以及原有 `generate_report`。Python 使用 `project.objects.sensor()` 创建句柄，`sensor.update()` 原子修改视场、基准指向与 `sensors.Orientation` 三轴偏转；`AccessSession`、`AccessSample`、`AccessInterval` 和 `observe_ground_target` 延续原计算接口。文件层的 `ProjectSensor` 与 `SensorPointing` 保留为低层值；新脚本用法见[对象编辑 API](object_editing.md)。

可运行示例见 [access.py](../../examples/python/access.py)。Access／AER 报告的 `object_ids` 必须恰为 `[地面站 ID, 卫星或传感器 ID]`，不接受空列表代表“全部”。

## STK 对照与验证

参考 STK [Access Options](https://help.agi.com/stk/Content/stk/tools-01a.htm) 的采样发现、事件边界收敛与固定步长设置；本实现保留固定模式，新增极值辅助发现，按照“采样发现与边界收敛分开”的设计组织；没有实现 STK 的完整自适应频率估计、光行时等选项。参考 [Basic Constraints](https://help.agi.com/stk/12.7.0/Content/stk/constraints-01.htm) 的地面仰角、地球遮挡与视场约束，以及 [Sensor Definition](https://help.agi.com/stk/Content/stk/sn-01.htm) 的 Simple Conic 半角定义。

对比 STK 时应统一轨道模型、时间／EOP、WGS84 站点、最低仰角、地心指向或理想目标跟踪、关闭光行时／折射／地形，并缩小搜索步长检查短事件。此阶段未取得 STK 同配置运行输出，不能声称数值已与 STK 对齐。

自动验证包含圆轨道地平线解析解、圆锥边界解析解、ENU 与距离变化率、端点截断、零长度接触、发现步长限制、取消、数据不匹配、所有权、当前项目往返及非当前格式拒绝。桌面回归检查对象绑定、删除后不改绑、AER 曲线、子对象属性、关闭草稿、保存重开与时间跳转。真实 GPU smoke 沿用[图形验证入口](../development/build.md)，新增传感器与 Access 交互案例。

新增过境极值、摘要、CSV 和搜索模式由 C++ / Python 共用。`Analysis.access(..., search_mode=AccessSearchMode.EXTREMUM_ASSISTED)` 返回 `window.extrema.maximum_elevation`、`minimum_range`（各含 `epoch` / `value`）和 `windows.statistics`；也可显式选择 `FIXED_GRID`。`Analysis.report(ACCESS_INTERVALS, ..., event_search_mode=..., boundary_tolerance=...)` 使用相同计算路径。独立数值验证和复现命令见[过境验证协议](../validation/access_pass_protocol.md)。
