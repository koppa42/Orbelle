# J2 长期项模型与接口

采用固定 GCRF 赤道面的名义轴对称地球，一阶长期项平均根数 `J2MeanElements(a,e,i,Ω,ω,M)`。常数来自 [IERS Conventions 2003 表 1.1](https://iers-conventions.obspm.fr/archive/2003/tn32.pdf)：μ=3.986004418×10¹⁴ m³/s²、参考赤道半径6378136.6 m、未归一化 J2=1.0826359×10⁻³，模型标识 `earth-iers2003-v1`。μ 沿用现有二体名义值；动力学参考半径与显示用 WGS84 椭球各司其职。该模型沿连续 TAI 秒演化，不声称实现相对论尺度改正或随日期变化的地球重力轴。

令 `n₀=√(μ/a³)`，`p=a(1−e²)`，`q=J2(R/p)²`：

- `Ω̇=−3/2 n₀ q cos(i)`；
- `ω̇=3/4 n₀ q (5 cos²(i)−1)`；
- `Ṁ=n₀[1+3/4 q √(1−e²)(3 cos²(i)−1)]`。

a、e、i 不变。标准桌面 J2 同时计入三个长期项，不提供独立开关；特殊倾角下某项变化率为零由公式决定。底层 C++/Python API 保留单项开关用于诊断对照，默认全部开启；关闭任何一项都不是完整的一阶 J2 长期模型，选项写入结果算法标识。严格使用 n₀ 计算一阶项，没有把修正后的平均角速度再乘进进动率。模型类别与 [STK J2 Perturbation](https://help.agi.com/stk/Content/stk/vehSat_orbitProp_2bodyJ2J4.htm) 一样只含长期变化；未实现 STK 的完整选项或其状态映射。根数到椭圆状态复用 [CSPICE conics_c](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/cspice/conics_c.html)，调用仍受统一 CSPICE 锁保护。

位置来自演化后的平均椭圆；输出速度为该位置的解析导数：`v=(Ṁ/n₀)v_K + Ω̇ z×r + ω̇ ĥ×r`。这与只报告开普勒辅助速度的模型不同，保证 Hermite 插值的切线与传播轨迹相容。

输入仅支持闭合、近地点高于中心天体参考面的平均椭圆。辅助 Cartesian 状态的转换 API 明确命名 `j2_mean_ellipse_state/elements`，不进行短周期改正，也不把二体瞬时根数、Brouwer-Lyddane 或 SGP4 平均根数无标记互用。桌面切换传播器时以当前几何椭圆重新定义输入并提示这一点。

GCRF↔ITRF 输入换算复用 ERFA/IERS 的完整状态变换 `R v + Ṙ r`。初始历元缺少 EOP 时拒绝切换，保留原草稿，不做隐式近似。ITRF 采用 Cartesian 输入；根数始终转回 GCRF。参考系与参数保存在对象输入和项目文件中，打开项目时按已确认的数据重建。

## 检验与限值

- 独立标量 Newton 解 `E−e sin(E)=M`，再以偏近点角构造轨道平面位置并旋转，生成 C++/Python 中的固定参考位置。LEO：a=7000 km、e=.01、i=98.5°、Ω=25°、ω=70°、M=10°；检查初始历元、正负1天和正负30天。另检查a=26600 km、e=.7的临界倾角椭圆。位置偏差≤1 mm。这是独立求解实现对同一模型的检验，不是独立物理模型或 STK 对照。
- 在顺行、极轨、逆行和赤道轨道上，使用 ±.125 s、±.25 s 的五点差分检查速度；每分量偏差≤2×10⁻⁵ m/s。分别验证完整长期项与单项启用。
- 赤道圆轨道使用独立封闭角速度表达式检查位置/速度；J2=0 或关闭全部长期项时，与现有 CSPICE 二体传播的差异≤1 mm、≤10⁻⁶ m/s。
- 验证平均椭圆辅助状态往返、奇异圆/赤道根数、无效/开放/穿地输入拒绝及不可变对象并发随机查询。
- 在已安装的 IERS 快照内，J2 默认60 s显示缓存的GCRF、ITRF四分之一段抽查误差均≤1 m，并保持按需一圈缓存策略。此为显示采样检查，不是轨道预测精度。
- 桌面控件检查实际速度项、参考系往返、无EOP时草稿回滚、J2平近点角语义；模型信息不包含重复的采样步长或长期项开关，关闭/重开不提交或覆盖属性草稿。真实GUI冒烟检查传播器切换后发布的轨迹，算法标识必须包含 `node=1;apsis=1;mean=1`。

复现入口：C++ / Python 的 J2 测试及桌面图形检查，命令见[构建说明](../development/build.md)。
