# 报告与曲线

参考 STK 的模板、数据提供器与对象绑定方式，报告计算使用 Orbelle 的 Runtime。桌面和 Python 共用同一个生成、格式化和 CSV 导出实现。

## 使用

打开场景后选择“分析 → 报告”。左侧依次设置对象范围、报告类型、时间与采样、显示格式；右侧切换表格与曲线。顶部可收起设置，扩大结果区域。报告使用现有工作区标签，可分屏或弹出。

对象右键菜单打开报告时只绑定右击的对象，并在左侧持续显示对象名称和范围。切换内置报告类型保持对象绑定；不适用的类型不可选。对象增加不会扩大绑定范围，对象删除后生成报错。通过“选择对象…”打开统一的“对象选择窗口”，明确选择全场景或多个对象；加载已经保存的配置会恢复该配置自己的对象范围。

对象名称不参与数值输入指纹。只改名称不会使计算结果过期、取消正在生成的报告或触发重新传播；桌面更新当前有效报告的名称列、对象对名称和曲线图例，同时保留数值、采样、表格选择和曲线时间范围。已失效的历史结果与 SDK 返回的不可变结果继续保留生成时名称。CSV 导出使用当前显示结果的名称。

报告类型字段打开独立的“选择报告”窗口，不使用随模板数量增长的下拉列表。窗口支持名称、内容和对象搜索，以及全部 / 内置报告 / 项目模板筛选。列表显示报告名称和输出用途，项目模板同时显示类型与绑定对象，便于区分同名项；旁边按内容说明、输出形式和对象范围分区预览。窄窗口改为上下排列，并保留各布局的分隔位置。不适用的内置报告可查看原因，但不能确认；已删除对象的模板保留原绑定，载入后可修正范围。确认才切换报告，取消或再次选择当前项保留未应用设置和已有结果。同名模板按稳定 ID 区分；窗口打开期间项目更新会同步候选，已删除的模板不能被误选成另一个模板。

顶部文档工具栏集中设置切换、本次结果名称、刷新（F5）与当前视图的 CSV/PNG 导出；复制和来源信息位于结果菜单。来源在单独详情窗口查看，不占用结果面积。窄分屏通过“编辑设置 / 查看结果”切换，生成成功后显示结果；宽屏同时展示设置和结果，生成操作固定在左侧底部。“模板 → 另存为模板…”复制当前绑定和设置并创建独立 ID；内置模板保持不变。结果表支持多选行、直接复制按钮、右键复制或 Ctrl+C，复制内容带列标题。常规精度为 9 位有效数字，事件数值使用 3 位小数；精度菜单另提供 6 位、12 位和完整精度（17 位）。悬停、复制和 CSV 始终保留完整精度；屏幕时间省略无意义的尾随零，完整精度下事件时间保留纳秒。

点击表头按数值、精确历元或文本排序，第三次点击或“原始顺序”恢复源表行序。排序使用代理模型，不修改不可变结果；复制按当前可见行序输出，CSV 仍输出完整源表顺序。双击、区间右键定位和复制均将可见行映射回源行。新计算发布时恢复源表顺序并禁用没有选择时的复制按钮。显示精度不改变排序键，也不触发计算；“适合列宽”按当前显示调整宽度，平时可拖动表头边界。数值和历元采用等宽字形。右键单元格可复制完整值，有时间曲线的数值列可加入现有曲线比较或只显示该列；表格工具栏的“曲线…”和右键“选择曲线…”均打开同一多选窗口。

表格工具栏与右键菜单的“显示列…”打开可搜索的列选择窗口。勾选决定表格、复制与 CSV 的字段，上移／下移或 Alt+↑／↓ 调整顺序；全选、清空和默认列便于快速修改，至少保留一列才能应用。搜索保留隐藏项的勾选，清空搜索后才能调整顺序。取消不改动结果；窗口打开期间查询、格式或场景变化时拒绝过期选择。默认列优先显示常用信息，稳定 ID、区间截断标记及部分极值时刻可按需加入；CSV 不再额外导出界面未选择的列。

选列只重排已有结果，不传播轨道或重建曲线。列宽按字段 ID 保留，隐藏再恢复同一字段仍沿用手动宽度；重排、改单位和时间系统保留仍显示字段的排序、选中源行及滚动位置。移除排序字段后恢复源行序。自动列宽限制长文本占用，完整文本保留在提示和复制中；表格单行显示并支持平滑滚动。保存与当前结果匹配的模板只更新名称和定义，结果继续可用。

“整个场景”包含以后插入的适用对象；“对象选择窗口”中取消“全部适用对象”后可勾选具体对象。窗口仅列出当前报告适用的类型，支持名称、路径和 ID 搜索；筛选隐藏对象不取消已有勾选。清空选择不等于全场景，至少选择一个有效对象或明确启用全部适用对象后才能确定。重命名不改变绑定，删除对象后保留配置并在生成时报告缺失，避免无提示地产生不完整报告；取消选择窗口不修改原范围。

所有时间序列报告可跟随场景范围或使用场景以内的自定义区间。步长是整数纳秒，包含起点和终点；不整除时额外保留精确终点，最后一段较短。允许单时刻查询。每个对象的行连续排列，顺序采用项目的卫星、地面站顺序。

报告类型旁的“模板”菜单提供保存、更新和删除；选择“保存为模板…”时才输入名称。保存把定义加入当前项目并标记未保存；再保存项目后写入磁盘。项目 v49 保留配置，不保存数据表；开发阶段只读写当前格式，不兼容旧项目版本。取消生成或生成失败保留上次结果；改变查询仍保留上次结果并提示重新生成；仅修改显示单位或时间系统，且查询与场景输入未变时，直接复用已有结果。格式应用失败保留原结果。结果页显示所对应的报告名称，场景输入改变后提示重新生成。双击含历元的行可定位场景时间。

星间报告使用有序双卫星绑定，要求 UTC/EOP；连续距离极值包含不可见时段，详见[星间分析](intersatellite.md)。

Access / AER 使用明确的地面站与目标对象对，参见[可见性与传感器](access_sensors.md)。Access 输出区间并联动时间轴，不显示区间端点之间的数值折线；AER 输出时间序列与可见标志。

## 曲线与模板操作

左侧固定主操作只有“生成报告”，采用标准宽度按钮；对象、类型、采样与单位按顺序排列，以细线分组。表格紧贴结果区边缘，结果视图栏仅显示当前数据支持的表格、曲线或热力图入口，计数与过期提示位于同一行。过境、光照、轨道事件和覆盖摘要采用紧凑统计栏，窄时排成两列。报告类型旁的模板菜单保存当前选择，使用已保存模板时可原地更新或另存新模板。取消命名不改变项目。模板属于当前项目，保存项目才写入磁盘；界面不再常驻“配置名称”输入框和底部保存按钮。

右侧在“表格 / 曲线”间切换。“选择曲线”窗口从本次结果读取数值字段，可按名称、字段 ID 或单位搜索，勾选最多 6 个字段。搜索不清除隐藏项的勾选；至少选择一项才能应用，取消不改变图形。应用前核对结果身份，结果在窗口打开期间已更新时要求重新选择。同显示单位的字段叠加，不同单位分成上下对齐的绘图区，共享时间范围、缩放、平移和时间游标。曲线用颜色、线型及“字段 · 对象”图例区分；每个绘图区图例最多三行，其余可通过悬停识别。窄窗口保留图形最小高度并支持纵向滚动，PNG 包含所有绘图区。

同一报告窗口按报告类型记忆已选字段 ID，重新生成、切换单位和重排显示列后保留仍存在的选择；不将图形视图状态写入项目模板。曲线对象字段打开统一的“对象选择窗口”，可对比最多 12 个对象或单独查看对象，候选 ID 与名称取自本次结果；当前有效结果的对象名称随重命名更新；对象删除后保留旧结果并标记过期。超过 12 个对象时选择单个查看，完整数据仍保留在表格和 CSV。静态摘要不显示时间曲线。字段、对象选择、显示单位和缩放复用同一不可变结果，不触发传播；修改左侧采样或参考系须重新生成。

曲线工具栏提供框选/平移模式、放大、缩小和全范围。支持滚轮以指针为中心缩放、中键拖动或方向键平移、右键/Home 还原、加减键缩放，以及双击附近采样点定位场景时间；Esc 撤销正在进行的拖动，无拖动时还原范围。字段、对象或显示单位切换保留当前时间范围，新计算恢复完整范围。悬停用十字线定位原始样本，并显示精确时间和值。横轴以报告起点为零，自动使用秒、分钟或小时，明确标示起点及 UTC/TAI/TT。纵轴按可见数据自适应，不为凑整刻度扩大上下边界；光照比例仍固定 0–100% 或 0–1。经度与周期性轨道角跨越半周时断线。绘图按横向像素保留首尾及极值点，避免降采样抹去单点尖峰；这只影响绘图，不改变表格。连线是离散样本的视觉连接，不是新增计算值。

图表页导出 PNG（2 倍分辨率）或从结果菜单复制图片；表格页导出 CSV、复制选中行。图片包含字段、单位、图例和时间起点，采用当前缩放范围；文件选择器负责覆盖确认，PNG 通过 QSaveFile 原子替换。图形的视图状态和 PNG 不写入项目，当前模板保存的是查询定义。

曲线坐标轴与线条按当前设备像素比缓存，悬停游标和框选范围单独绘制。结果、字段、对象、时间范围、尺寸、字体或样式改变后重建；跨 DPI 时按新像素比重建。缓存仅保留一个视口，超过 64 MiB 时退回直接绘制；PNG 始终按导出分辨率重新绘制，不放大屏幕缓存。纵轴范围用每 128 个原始样本的精确最小／最大值块加速查询，边缘不足整块的部分仍逐点读取；每像素的首尾与极值点选择、断线位置及原始数据保持不变。

## 计算与数据一致性

Application 提供 `ReportQuery`、`ReportTemplate` 和组合两者的 `ReportDefinition`，以及共享字段定义 `report_columns(kind)`。Results 提供不可变共享存储的 `Table`（列 ID、名称、基础单位和有类型单元格）。桌面、Python 和 C++ 项目 API 通过 `Analysis::report()` 使用已准备的 Session 与共享表格引擎；低层 `ReportContext` / `generate_report` 仍作为适配入口。报告不读取显示轨迹 `StateTrack`，地图插值不影响结果；轨道步长只在启用 HPOP 固定星历输出时参与科学计算，报告查询的采样间隔仍独立。卫星和地面站的跨参考系计算使用完整状态变换，包含地球旋转引起的速度。

桌面每次生成前检查当前数据是否覆盖完整场景，以及数据身份/外推策略是否与已确认场景一致。变化时沿用场景的数据确认流程：取消则不生成；同意后先重建场景，成功后自动继续报告。一次报告捕获项目、时间/EOP Provider 的共享不可变版本，下载或后续场景编辑不改变运行中的输入。覆盖不足或 UTC 过期不会静默外推；有限 EOP 外推仍由数据中心控制。

桌面将预检查返回的项目值、已加载 Provider 和当前场景的科学会话缓存交给后台，通过 `ProjectDocument`、`runtime::prepare()` 和 `Analysis::report()` 完成计算，准备步骤不会自动接受额外的数据变化。预检查返回时核对当前输入；生成期间输入或数据变化会取消任务，并通过递增代数阻止旧结果发布，即使输入随后改回原值也不会恢复该任务。失败、取消和过期结果保留上次表格。播放时间、报告模板和纯图形设置不使正在生成的结果失效。结果发布同时保留其 `Analysis`，地图与时间轴的可见性会话复用这份分析的对象和 Provider。

同一报告页再次生成时，在预检查之后比较项目输入、结果标签、完整数据身份与参考系 Provider；一致时复用上次成功发布的 `Analysis`，直接执行新的查询。切换报告类型、查询采样或对象范围不重新创建传播会话。播放时刻、已保存模板及纯外观设置不影响此复用；名称、物理输入或资源变化会重新准备。失败和取消不替换可复用的已发布分析。

首次报告和重新准备的 Analysis 通过 `runtime::OrbitSessionCache` 复用视图已准备的科学 Session。每个对象保留一个当前会话，匹配有效物理输入、实际使用的数据身份及必要的参考系 Provider；HPOP／任务序列还匹配计算区间。任务段名称参与匹配，防止机动结果返回旧标签。报告保留本次文档修订，Session 的数值 Provider 可共享，来源修订不会沿用桌面对象的计数。候选场景先复制缓存索引，全部计算和图形准备成功后才一起发布；取消或失败不替换当前缓存，删除对象时移除其条目，旧分析仍持有所需资源。缓存不跨场景或进程持久化，不读取显示轨迹，不改变报告采样与数据确认规则。

结果记录捕获文档的修订、输入 SHA-256、场景数据锁、UTC 数据 SHA-256 和对应算法标识：常规报告为 `builtin-reports-v2`，协方差为 `hpop-joint-covariance-sequential-samples-v2`，可见性为 `geometric-access-wgs84-local-ground-v2`，光照为 `geometric-lighting-earth-sphere-v1;uniform-solar-disk-v1` 并附太阳星历选择与事件搜索方式。输入哈希使用规范项目编码，排除对象显示名称、地面站描述及坐标表示、报告配置、播放时间和卫星、传感器图形设置，保留固定对象 ID、物理输入和数据身份；HPOP 固定星历输出启用时保留轨道步长，否则将其排除。该哈希用于识别变化，不是结果缓存键或来源签名。桌面尚未将整个工作台的编辑流程迁入统一文档，因此报告修订来自本次捕获文档；任务是否过期还由界面的输入代数和资源身份校验。

后台任务每批最多 512 个样本，支持进度与取消；桌面表格按需格式化。单次最多 **200000 行**，生成前检查上限；超限应增大步长、缩短区间或减少对象。结果仍驻留内存，尚未实现磁盘分页和无限量导出。

多对象采样报告在一次执行内复用相同历元的 GCRF／TEME 到 ITRF 完整状态变换，沿用原有参考系路由及旋转率速度项。缓存绑定本次捕获的不可变 Provider，最多保留 8192 个“变换类型、TAI 纳秒历元”条目；超出部分按原算法计算，不插值或外推。缓存不跨报告、数据版本或线程共享，单对象报告仍直接计算。

根数调用现有 CSPICE 状态转根数实现；J2 输出是采样状态换算的瞬时根数，不是模型输入的平均根数。圆/赤道轨道采用 Provider 的奇异角约定，抛物线或数值病态情况明确报错，不伪造数值。经纬高使用 ERFA `eraGc2gd` 的 WGS84 转换，卫星先通过已确认 EOP 转到 ITRF；椭球高不是离地高度。速率中径向向外为正，横向速率非负，航迹倾角为 `atan2(径向速率, 横向速率)`。

## 单位与 CSV

内部数值始终使用 m、m/s、rad 和 TAI 整数纳秒；工程格式使用 km、km/s、度。UTC 文本保留闰秒，TAI/TT 不带 UTC 的 `Z` 标记，列头明确时间系统。数值格式化采用经典区域设置与 17 位有效数字；时间保留 9 位小数。

CSV 使用 UTF-8 BOM、逗号分隔、双引号转义和 CRLF 行结束符，支持中文、逗号、引号和名称内换行。先写入同目录临时文件，成功后原子发布；默认不覆盖，桌面覆盖须通过文件选择器确认。取消/发布前失败保留旧文件。CSV 只包含表格，不插入哈希前言；本次溯源信息可在来源窗口和 Python 结果对象中读取，暂不自动导出元数据附属文件。

## 查询与呈现

`ReportQuery` 只描述查询类型、对象范围、区间、步长和参考系；`ReportTemplate` 描述显示列、顺序、逐列单位/标题及默认单位和时间系统。`ReportDefinition{id, name, query, format}` 用于保存配置。Python、C++ 和桌面使用同一套字段定义、校验与文件结构。空对象集合不再隐含全选；普通查询需绑定对象，或显式使用 `ReportScope::all_compatible`（Python `ob.reports.ALL`）。全选始终在捕获的分析/项目范围内生效。

生成时保留完整原始 SI 表。`ReportResult::with_template()` / Python `Template.apply()` 返回新呈现，可以重新显示先前隐藏的字段；不创建传播器、不读取数据文件、不重新采样。单元格数值仍是 SI，历元仍为精确 `Epoch`；显示值通过 `numeric_value()`、`cell_text()`、CSV 和绘图一致转换。单位覆盖只影响对应列；场景摘要的起止时刻也保留类型，可重新选择时间系统。实际显示 UTC 时才检查已捕获的 UTC 数据；不含时间列的表不因默认 UTC 而强制加载数据。

桌面的单位、时间系统和显示列可以立即应用；保存的列顺序、单位和标题在加载、生成和再次保存时保留。绘图按字段 ID 从完整原始表寻找对象、时间和数值字段，隐藏表格列不移除曲线候选，也不改变多字段选择或缩放。自定义字段隐藏后，其单位和标题在本次结果内保留；重新生成以保存模板为准。曲线时间标签仍要求所选时间系统的数据覆盖；表格未显示时间时可以独立使用。可见性时间轴同样使用完整原始区间，不受显示列影响。桌面默认显式选择常用列；C++ 空 `columns` 和 Python `columns=None` 仍表示全部字段，公共接口与项目格式未变。

## Python

```python
import orbelle as ob
from orbelle import units as u

# analysis 已由 project.prepare() 捕获，satellite 为项目对象句柄。
template = ob.reports.Template([
    "time.epoch",
    ob.reports.Column("state.x", unit="km", title="X"),
    ob.reports.Column("state.vx", unit="m/s"),
])
result = analysis.report(ob.ReportKind.CARTESIAN_STATE, objects=satellite,
                         step=u.s(30), template=template)
result.export_csv("state.csv")
# 恢复完整字段并改成 SI，不重新计算。
si = ob.reports.Template(units=ob.ReportUnits.SI).apply(result)
print(si.numeric_value(0, 4))
project.set_reports([result.definition])
project.save("mission.orbelle")
```

省略模板仍可使用 `units=`、`time_scale=` 便利参数；提供模板时两者须写入模板，避免重复配置。Python 默认工程单位与 TAI，`columns=None` 使用完整字段，显式空列表报错。`ob.reports.fields(kind)` 返回字段 ID、默认标题和原始维度。`Template` / `Column` 为不可变配置值，`Template.apply()` 目前接受 `ReportResult`，其他类型结果继续使用各自的导出/数组方法。保存配置通过 `project.set_reports()` 整体校验并提交，读取可用 `project.to_data().reports` 副本。完整可运行示例见 [report_templates.py](../../examples/python/report_templates.py)。

## C++

```cpp
namespace app = orbelle::application;
app::ReportQuery query;
query.kind = app::ReportKind::aer;
query.object_ids = {station.id(), sensor.id()};
query.step_nanoseconds = 10'000'000'000;
app::ReportTemplate format;
format.time_scale = app::ReportTimeScale::tai;
format.columns = {{"time.epoch", "TAI", ""}, {"aer.range", "km", "Slant range"}};
auto report = analysis.report(query, format);
auto full = report.with_template(app::ReportTemplate{.time_scale = app::ReportTimeScale::tai});
```

C++ 的原生模板默认 UTC；无 UTC 数据时显式选 TAI/TT。独立 `generate_report(context, definition)` 与 `Analysis::report(query, format)` 共用引擎；前者从捕获项目创建会话，后者复用准备好的会话。Python 原生绑定在释放 GIL 前复制输入配置；结果返回拥有完整来源的不可变表和配置副本。

### 界面调整采用的取舍

STK 的报告管理器把对象类型/对象列表、Styles、Time Properties 和 Generate 分区组织，先选对象再选适用样式；报告生成后在结果窗口提供操作工具栏。它不是左侧设置、右侧实时结果的布局。[管理器与对象范围](https://help.agi.com/stk/Content/stk/report.htm)、[官方界面教程](https://help.agi.com/stk/content/training/L1_AccessReports.htm)

Orbelle 采用左侧设置、右侧结果的布局，借用其对象优先、适用类型筛选、结果工具栏三个特点。报告选择放在独立的可搜索窗口中，区分内置报告和项目模板，主面板只显示当前选择。时间默认使用场景时段，只有选择自定义时段才展开两个时间输入框。配置管理与来源详情保留明确入口，不占用主结果区域。

## 可见性与过境报告

Access 报告增加连续最大仰角、最小斜距及对应时刻，与 Analysis.access 共用计算。`ReportQuery.event_search_mode` 默认极值辅助发现，`step_nanoseconds` 表示最大检查间隔；固定模式保持原网格语义。`event_tolerance_nanoseconds` 默认 1 ms，影响事件细化及连续极值搜索。报告保存 `access_statistics`，修改模板只重排／换算原数据，统计不重新计算。摘要不依赖当前显示列；完整源表支持从极值单元格直接定位。原 AER 报告继续包含不可见采样时刻。

默认过境表突出起止、持续时间、最大仰角、最近距离；稳定 ID、截断标记、极值历元保留在完整源表，可通过“显示列…”加入表格与导出。支持字段 `access.max_elevation`、`access.max_elevation_time`、`access.min_range`、`access.min_range_time`。区间截断以 `*` 和提示显示，窄窗口保留表格横向滚动和两列统计栏。所有数值与界面使用同一结果，见[过境协议](../validation/access_pass_protocol.md)。


## 光照与地影

参见[光照模型与数据契约](lighting.md)。两种报告都选择卫星，独立于传播器和 SRP 开关。时段表显示全光照、半影、本影及精确边界；摘要显示三种状态的时间占比和最长本影，多对象按各卫星时间分别累计。双击开始/结束时刻或右键定位可跳转场景时间。光照比例报告输出 0–1 的原始值，工程显示为 %，沿用曲线、CSV、PNG 与模板功能。时段报告不将事件边界连接成数值曲线。

桌面首次执行光照查询时，将数据中心的指定太阳星历加入当前场景资源并在后台准备；后续重算/重开核对已记录身份。未安装或覆盖不足时明确报错。C++/Python 需在准备前显式提供 `DataSnapshot.with_ephemeris`，或让目录准备已保存光照模板所需的资源；查询过程中不加载或下载文件。
