# HPOP 总力与局部变分入口

C++ / SDK `evaluate_hpop_acceleration(state, options, environment)` 返回与传播器相同的总加速度；`hpop_force_differential(...)` 返回总加速度、3×3 位置与速度 Jacobian，以及 [STK consider 参数](https://help.agi.com/stk/Content/hpop/hpop-covariance.htm) `D=Cd×DragArea/Mass`、`K=Cr×SRPArea/Mass` 的局部力偏导。它们是单历元接口；[单段变分传播](hpop_variational.md)使用相同装配积分 STM 和参数敏感度，[联合协方差](hpop_covariance.md)使用它们传播初始状态、D/K 方差与交叉项。

输入为 Earth / GCRF、TAI 接收历元和 SI 状态。输出仍为同一惯性轴：加速度 m/s²、位置 Jacobian s⁻²、速度 Jacobian s⁻¹、D/K 偏导 Pa；矩阵行为加速度分量，列为输入分量。固定外部星历、时间、地球定向、天气、资源和模型参数；卫星视太阳本身的状态依赖仍按[视太阳状态链](apparent_sun_differential.md)求导。

## 共用模型装配

HPOP 的每阶段名义力、独立瞬时查询和局部偏导使用同一装配实现。通过编译期选择名义或偏导路径，普通传播不计算 Hessian、密度梯度或视太阳偏导。求和顺序保持中心引力及其修正、三项相对论、按表顺序的第三体、SRP、阻力。

| 力项 | 装配语义 |
| --- | --- |
| 中心引力 | 当前球谐截断、长期率、固体潮和海潮使用同一系数准备与合并顺序；固定历元的修正系数对卫星状态独立 |
| 相对论 | 使用几何太阳状态和惯性轴中的地球极轴；累加三个已验证的状态块 |
| 第三体 | 每个启用天体使用自己的 GM 来源；GM 验证先于位置查询；几何地心差分加速度 |
| SRP | 使用所选太阳方法的完整局部状态块及 K 偏导，包括卫星视太阳的位置和速度依赖 |
| 阻力 | 在 ITRF 求密度、气流相对速度和局部偏导，再应用完整状态变换；D 偏导旋转回惯性轴 |

设惯性到 ITRF 的位置旋转为 R、每 TAI 秒导数为 Rdot，`r_f=Rr`、`v_f=Rv+Rdot r`。固定历元下：

```text
Jr = Rᵀ (Jr_f R + Jv_f Rdot)
Jv = Rᵀ Jv_f R
d_a/d_D = Rᵀ d_a_f/d_D
```

重力的地固速度块为零，因此只保留 `Rᵀ Hessian R`。阻力必须保留位置到气流速度的耦合。关闭的力项及其参数块为零；模型启用但 D/K 为零时，名义加速度可为零，参数敏感度仍保留。

## 资源、事件与接口边界

瞬时入口复用传播器的选项、重力选择、GM、EOP/UTC 身份、星历覆盖、天气及潮汐依赖校验，再检查状态有限性与最低参考球面高度。默认资源选择只作用于传入环境的私有副本。没有隐式下载或数据外推；资源仍由 Runtime / 数据中心准备。取消回调可以抛出，返回前不发布部分结果。

名义传播内部继续接收天气段的单侧取样历元和圆柱阴影单侧照明值；独立瞬时 API 使用该点的正常模型定义，没有用于伪造事件侧的公开覆盖参数。偏导保留[阻力的分界及极点限制](drag_differential.md)和[SRP 接触限制](srp_differential.md)，遇到不支持的偏导明确失败。

本单历元接口使用相同的重力阶次；变分传播另外支持独立阶次，只改变空间偏导。联合协方差已按正定矩阵政策接入；圆柱／硬密度切换的事件跳变仍待实现。本入口也不是对积分算法、VOP 坐标或 Sundman 时钟的导数。项目结构保持 v41 / OBJS32；没有新增桌面开关。低层组合 API 随 SDK 导出，Python 现有传播继续使用同一名义路径；Python 已提供单段变分／协方差接口，本瞬时总力入口尚未单独绑定。

独立 Orekit 组合对照、潮汐装配检查和名义重构回归见[验证协议](../validation/hpop_force_protocol.md)。
