# 区域覆盖与重访分析

覆盖定义由 WGS84 地表网格、明确选择的 1–2048 个卫星或传感器、分析时段和可见约束组成。`coverage_grid` 报告网格统计，`coverage_time` 报告随时间变化的覆盖面积；两者共用 Runtime、科学轨迹和不可变 `CoverageStatistics`。桌面热力图、C++ SDK、Python 和 CSV 使用同一计算结果。

## 与 STK 的对应关系

采用 STK Area Target → Coverage Definition（区域、资产、采样设置）→ Figure of Merit 的组织方式：经纬度区域或全球范围、Simple Coverage 的瞬时与曾覆盖面积、Coverage Time、Revisit Time。面积比例按网格面积加权；重访指没有任何资产覆盖的时间空档，区别于相邻过境起点间隔。

参考官方定义：[覆盖网格](https://help.agi.com/stk/Content/cov/covdef-01.htm)、[Simple Coverage](https://help.agi.com/stk/content/cov/fom-02.htm)、[Revisit Time](https://help.agi.com/stk/content/cov/fom-05.htm)、[Percent Coverage](https://help.agi.com/stkdevkit/Subsystems/dataProviders/Content/html/dataProviders/Percent_Coverage.htm)。生产实现不调用 STK。数值验证包括 Orekit 独立固定参考，以及实际 STK Engine 11.6 的同星历、同点集覆盖与重访对照；方法见[覆盖验证](../validation/coverage_protocol.md)。STK 自定义点集仍使用其粒度设置分配点面积，因此相同点集并不意味着原生百分比使用相同面积权重；对照分别报告统一权重下的计算差异及原生面积口径差异，不声称复制了 STK 内部网格算法。

## 创建区域 → 覆盖性分析报告

在“插入对象 → 区域”中命名并创建经纬度矩形或多边形，在区域属性中设置网格间隔，应用后成为场景树中的独立对象。右键区域选择“覆盖性分析”，再明确选择卫星／传感器资产；报告设置最低仰角、时段、搜索步长和首尾空档策略，点击生成。也可从报告库选择两种覆盖报告，再选择区域和资产；不会自动选中第一颗卫星。报告显示区域网格摘要，并通过“区域属性…”打开对应区域，不重复编辑边界和间隔。

区域可重命名、复制、删除，边界与备注在属性页编辑；选中后可定位二维地图和三维地球视角。关闭属性页保留草稿，应用后才进入场景；保存项目后保留区域和报告绑定。一个区域可复用于多份报告。删除区域保留报告的缺失绑定并阻止重新生成；旧结果仍可查看，不会悄悄切换到另一范围。

区域属性沿用对象属性页的导航、分组表单与固定操作栏，分为边界、网格、描述和二维/三维显示。窄面板切换为页签或页面选择器，切换页面或调整宽度保留未应用的输入和单位。显示页设置两种视图的可见性、共享颜色、填充开关和不透明度（默认 12%）。选中区域保留原色、加粗边界；填充表示区域范围，不代表已覆盖面积。显示设置不改变分析输入或使报告失效。

边界页提供独立的“区域示意”区，矩形和多边形共用同一布局：宽窗口与边界组顶部对齐，窄窗口统一放在下方。示意图随草稿自动适配范围，保留经纬度刻度并显示多边形顶点；复用二维的日期变更线裁剪，跨线区域在局部预览中连续显示。无效输入清除旧轮廓并提示。更新在界面事件循环合并，仅预览几何，不计算覆盖、不应用场景修改。

二维将连续经度边界裁剪到世界范围后缓存填充路径，跨日期变更线时不会误填中央地图。三维使用无光照着色的静态曲面网格，边界与填充共用 sRGB 颜色；按显示用途抬高 WGS84 表面 1 km，细分边长控制曲面弦的下陷。多边形先在包含区域的半球上投影并按凹多边形剖分，再细分球面三角形。几何仅在应用区域修改时建立，播放和选中不重建网格；这些显示近似不参与区域面积与覆盖计算。

多边形输入 3–256 个经纬度顶点，不重复首点，支持凹多边形和跨日期变更线。顶点用大地经纬度单位向量表示，边连接短大圆弧；沿弧的纬度极值也计入采样范围。首版要求位于经度跨度小于 180° 的条带中，不含极点、孔洞、自交、重叠边或重复顶点。矩形使用经纬线边界，可覆盖全球或极区。参考 [STK 自定义区域](https://help.agi.com/stk/Content/cov/covdef-01.htm)的区域对象组织和范围限制；这里的大圆弧模型不是椭球测地线，也不声称与 STK 内部离散化一致。

多边形逐行扫描包围矩形，只保留中心落在边界内的网格点；不在内存中展开整个候选点集。边缘网格不做几何裁切，因此总面积、覆盖面积和比例是网格估计；减小间距并比较结果以检查空间收敛。若没有网格中心落入区域，明确要求减小间距。候选点和保留点均没有固定数量上限，区域外候选点只消耗筛选时间，不占结果存储预算。

2D 和 3D 显示使用独立的、最大 0.5° 弧长间隔的轮廓缓存。3D 轮廓仅为避免深度闪烁抬高 1 km，分析点仍在 WGS84 零椭球高地表。播放只随地球参考系变换缓存，修改边界不会重新传播卫星；点击生成才在后台计算覆盖，可取消。报告保存捕获的边界和实际采样范围，修改活动区域不会改变已有结果。

## 网格与物理模型

`core::CoverageGrid` 的角度为弧度：南北界在 [-π/2, π/2] 内递增，西东界在 [-π, π] 内。西界大于东界表示跨日期变更线；[-π, π] 表示全球经度，等价的 [π, -π] 不表示区域。经纬度是大地坐标，椭球高固定为零。最低仰角为 [0, π/2]。间隔须为 (0, π]，维度和索引须能由 `size_t` 表示，相邻边界及正面积须能由浮点数区分。

纬向分为 `ceil((north-south)/resolution)` 个等宽带，每带以中纬度确定 `ceil(longitude_span*cos(latitude)/resolution)` 个经向网格，至少一个。每个网格中心代表该网格的可见性，网格范围边界沿经纬线。面积是 WGS84 椭球面积元 `M(φ)N(φ)cos(φ)dφdλ` 的解析积分，使用 a=6378137 m、f=1/298.257223563。高纬度经度间隔扩大，但仍使用精确面积权重，不能以网格点个数代替面积。

卫星资产采用地球遮挡与最低仰角；传感器再叠加其视场、基准指向和局部三轴偏转。对地心与理想站点跟踪均可；跟踪传感器的基准始终指向原有站点，偏转后的视场不保证包含站点，也不会自动重定向到每个网格点。支持连续二体、J2、J4、SGP4 和 HPOP 科学轨迹；含机动的任务序列明确拒绝。必须准备并确认 UTC/EOP 与所需轨道数据，轨迹不读取显示缓存，也不隐式下载。

## 时间统计

逐点、逐资产复用 Access 搜索，支持固定网格或默认极值辅助模式。最大检查间隔决定发现能力，边界容差决定求根精度；减半检查间隔核对收敛。任意复杂短事件仍可能要求更密的检查间隔。只有正时长区间计入覆盖，孤立相切接触不计入。重叠或相接区间取并集，不填平短于容差的实际空档。

- 每点输出网格面积、覆盖总时长、时长占比、并集区间数、最长及平均无覆盖空档。
- 默认包括区间开始至首次覆盖、末次覆盖至区间结束的空档；这些边界是截断后的乐观估计。关闭后只计内部空档。无任何覆盖的点，无论该选项如何都以整个分析时长作为唯一空档；始终覆盖的点为空档 0。
- 曾覆盖面积是出现过正时长覆盖区间的网格面积之和。平均覆盖率是各点覆盖时长占比按面积加权的结果。全局最长空档为各点最长空档的最大值。
- 时间序列始终包含分析起止时刻；瞬时覆盖面积由并集区间成员关系计算，累计覆盖面积由首次覆盖时刻计算。两个输出节点之间的覆盖不会被漏掉。区间两端使用可见侧根的闭区间约定。

分析时段必须为正，跨度须能表示为正 `int64` 纳秒。覆盖报告不设固定网格点数、输出时间节点数、存储区间数或累计计算次数上限。单任务默认使用 **512 MiB 可调整内存预算**：生成前保守估算工作区、完整点结果和表格（含模板转换）；生成中继续核算访问区间的存储开销。预算不足、资源分配失败、对象删除、传播失败及取消均报错并保留上次有效结果。扩大预算不会改变科学参数或自动降低分辨率。

网格按最多 1024 个保留点分批计算，时间搜索按原时间格点划分为最多 64 个步长的窗口。每个窗口先完成当前点批次的资产并集，再推进时间，避免逐点扫描整天或整周时反复淘汰可复用的轨迹与参考系转换。跨窗相接访问合并，截断标记以整个分析时段为准，重访空档跨窗连续统计。这些批次大小只约束工作区，不限制任务总量，也不改变搜索间隔或求根容差。时间曲线通过区间范围增量求和生成，避免每个输出节点重新扫描全部网格点。完整网格、合并区间和表格仍驻留内存；尚未实现磁盘分页，因此不能承诺任何规模都能在任意机器上完成。预算预留 64 MiB 工作区，另按数据结构及临时副本估算结果开销；不含输入轨迹 Provider、已打开的其他报告和调用方自行复制的数据，不是进程总内存硬限额。

轨迹缓存按父卫星和精确 TAI 纳秒索引，每颗最多保留 65536 个状态，每个时间窗内处理完同一父卫星的全部传感器后释放；单父卫星可跨批次复用。GCRF、TEME 的状态转换分别缓存最多 32768 个精确时刻，在资产间共享，并保留地球旋转速度项。缓存满时清空后继续计算，不因累计采样数而中断。超过 32 个父卫星时，按初始地固位置与速度方向的差异优先处理分散的轨道；该顺序不排除资产。固定网格点的地固位置与局部基准只计算一次；已覆盖时段不再重复搜索，待搜索空档向外对齐原始时间格点，保留可能发现短事件的完整括区；某点在当前时间窗完全覆盖后跳过其后续资产，但仍预先校验所有资产及轨迹端点。事件发现与求根沿用原算法，不量化或插值缓存历元。

报告设置在后台估算实际网格点数、资产数、结果行数与基础存储预算；修改设置会取消旧估算，长任务提供进度和取消。热力图缓存底图，选点只重绘标记，结果、指标、尺寸或 DPI 改变时重建。网格数量不代表精度保证，应分别减半空间间隔和时间搜索步长验证收敛。全球均匀分配 4096 点时等效间距约 350 km，窄幅观测通常需要更细网格。STK 官方没有在网格说明中给出统一固定点数上限；本机 STK Engine 11.6 的全球网格生成实测为 1° 43424 点、0.5° 160066 点，仅说明可生成该规模，不是最大容量或覆盖计算耗时保证。

## UI 与接口

在报告库选择“覆盖网格与重访”或“覆盖率时间曲线”。可搜索选择区域与卫星 / 传感器，在报告中设置最低仰角和首尾空档策略；边界与网格间隔统一在区域属性中编辑。SDK 内联矩形查询仍支持，新建桌面覆盖报告要求选择独立区域。四张统计卡片展示网格数、曾覆盖面积占比、平均覆盖率及最长空档。热力图支持切换时长占比 / 最长空档、悬停、点击或方向键选点、区间列表、场景时刻定位及 PNG/剪贴板；表格和曲线支持既有格式与 CSV 导出。窄窗口保留设置与结果切换，变化不触发重新计算。

Python 示例见 [coverage.py](../../examples/python/coverage.py)：`analysis.report(ob.ReportKind.COVERAGE_GRID, objects=[satellite], region=region, coverage=grid, step=u.s(60), coverage_memory_mib=1536)`。内存预算接受正整数 MiB，默认 512。`CoverageGrid` 是可编辑的 SI 配置；返回的 `coverage_statistics.points` 保留每点位置、面积、合并区间与统计，模板转换不会重算轨道。密网格优先使用 `point_count` 和 `iter_points()`，避免一次构造全部点的 Python 列表；迭代器保持统计对象存活，逐点返回独立值。ALL 模式不适用于覆盖资产。

C++ `ReportContext.coverage_memory_bytes` 或 `Analysis::report` 的末尾参数配置同一预算，`estimate_coverage_report` 返回点数、行数及保守的基础存储预算（不含尚未知的访问区间），并支持取消。Core 的 `coverage_grid_size` 可只统计点数，`visit_coverage_grid` / `visit_region_coverage_grid` 可流式访问网格；原有返回完整向量的接口保留。预算只影响任务执行，不写入项目、模板或科学输入哈希。

项目格式 v54 / REGN3 / RPTS8 保存区域和全部覆盖参数，包括非活动草稿；只接受当前格式，旧版本明确拒绝。结果不写入项目，模板保存查询输入。暂不包含地形/折射、多边形孔洞、自适应网格、概率覆盖、多重同时覆盖、重访百分位、通信链路及区域传感器规划。

C++ 使用 `Project.regions` / `ProjectRegion`、`objects::Region` 与 `ObjectManager` 的事务接口，`ReportQuery.region_id` 指定边界及 `grid_resolution_rad` 的来源；`coverage` 中的仰角与空档选项仍生效，内联边界和间隔是非活动草稿。Python 使用 `objects.region(name, boundary=regions.Rectangle(...), grid_spacing=u.deg(5))` 或 `regions.Polygon(tuple[regions.Vertex, ...])`，也可设置 `region.grid_spacing`；角度用 `units.deg/rad`，区域句柄和资产必须属于同一准备快照。结果的 `coverage_statistics.region` 与 `grid` 保存该次计算的边界和解析后的采样范围。修改区域间隔不会传播卫星，也不会修改已有结果。空 `region_id` 保留 SDK 内联矩形 API；桌面生成覆盖报告要求明确选择区域。

最低仰角属于“覆盖条件与统计”：从每个区域网格点看卫星时应用，可在同一区域上比较不同仰角条件；它不改变区域边界或点集。STK 同样通过 Coverage Definition 的[网格约束](https://help.agi.com/stk/Content/cov/covdef-02.htm)应用可见性条件。重访首尾空档属于统计口径，内存预算属于任务执行设置，均留在报告中。
