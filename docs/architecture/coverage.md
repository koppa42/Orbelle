# 区域覆盖与重访分析

覆盖定义由 WGS84 地表网格、明确选择的 1–32 个卫星或传感器、分析时段和可见约束组成。`coverage_grid` 报告网格统计，`coverage_time` 报告随时间变化的覆盖面积；两者共用 Runtime、科学轨迹和不可变 `CoverageStatistics`。桌面热力图、C++ SDK、Python 和 CSV 使用同一计算结果。

## 与 STK 的对应关系

采用 STK Coverage Definition → assets → Figure of Merit 的组织方式：经纬度区域或全球范围、Simple Coverage 的瞬时与曾覆盖面积、Coverage Time、Revisit Time。面积比例按网格面积加权；重访指没有任何资产覆盖的时间空档，区别于相邻过境起点间隔。

参考官方定义：[覆盖网格](https://help.agi.com/stk/Content/cov/covdef-01.htm)、[Simple Coverage](https://help.agi.com/stk/content/cov/fom-02.htm)、[Revisit Time](https://help.agi.com/stk/content/cov/fom-05.htm)、[Percent Coverage](https://help.agi.com/stkdevkit/Subsystems/dataProviders/Content/html/dataProviders/Percent_Coverage.htm)。本实现没有调用 STK，也未声称生成与 STK 完全相同的内部网格；数值对照采用公开固定网格与 Orekit 独立参考。

## 网格与物理模型

`core::CoverageGrid` 的角度为弧度：南北界在 [-π/2, π/2] 内递增，西东界在 [-π, π] 内。西界大于东界表示跨日期变更线；[-π, π] 表示全球经度，等价的 [π, -π] 不表示区域。经纬度是大地坐标，椭球高固定为零。最低仰角为 [0, π/2]。间隔须为 (0, π]，最多 4096 个网格点。

纬向分为 `ceil((north-south)/resolution)` 个等宽带，每带以中纬度确定 `ceil(longitude_span*cos(latitude)/resolution)` 个经向网格，至少一个。每个网格中心代表该网格的可见性，网格范围边界沿经纬线。面积是 WGS84 椭球面积元 `M(φ)N(φ)cos(φ)dφdλ` 的解析积分，使用 a=6378137 m、f=1/298.257223563。高纬度经度间隔扩大，但仍使用精确面积权重，不能以网格点个数代替面积。

卫星资产采用地球遮挡与最低仰角；传感器再叠加已有圆锥视场及指向。对地心与理想站点跟踪均可；跟踪传感器始终指向其原有站点，不会自动重定向到每个网格点。支持连续二体、J2、J4、SGP4 和 HPOP 科学轨迹；含机动的任务序列明确拒绝。必须准备并确认 UTC/EOP 与所需轨道数据，轨迹不读取显示缓存，也不隐式下载。

## 时间统计

逐点、逐资产复用 Access 搜索，支持固定网格或默认极值辅助模式。最大检查间隔决定发现能力，边界容差决定求根精度；减半检查间隔核对收敛。任意复杂短事件仍可能要求更密的检查间隔。只有正时长区间计入覆盖，孤立相切接触不计入。重叠或相接区间取并集，不填平短于容差的实际空档。

- 每点输出网格面积、覆盖总时长、时长占比、并集区间数、最长及平均无覆盖空档。
- 默认包括区间开始至首次覆盖、末次覆盖至区间结束的空档；这些边界是截断后的乐观估计。关闭后只计内部空档。无任何覆盖的点，无论该选项如何都以整个分析时长作为唯一空档；始终覆盖的点为空档 0。
- 曾覆盖面积是出现过正时长覆盖区间的网格面积之和。平均覆盖率是各点覆盖时长占比按面积加权的结果。全局最长空档为各点最长空档的最大值。
- 时间序列始终包含分析起止时刻；瞬时覆盖面积由并集区间成员关系计算，累计覆盖面积由首次覆盖时刻计算。两个输出节点之间的覆盖不会被漏掉。区间两端使用可见侧根的闭区间约定。

分析时段必须为正。上限为 200000 个输出时间节点、200000 个存储覆盖区间、5000 万次几何评估、500000 个独立轨迹采样。不同网格点及同一父卫星的传感器共享轨迹采样缓存。超限、资源不足、对象删除、传播失败及取消均报错且保留上次有效结果。

轨迹缓存按父卫星和精确 TAI 纳秒索引；每颗卫星使用只做查询、不参与输出排序的哈希表，取消和全局采样上限仍在查询路径上执行。平均查询成本为常数，桶数组占用与实际缓存条目数成正比；不提前为每颗卫星分配最大容量。事件发现、求根及区间合并仍由原有有序算法决定，不量化或插值缓存的历元。

## UI 与接口

在报告库选择“覆盖网格与重访”或“覆盖率时间曲线”。可搜索选择卫星 / 传感器，设置区域或一键全球、最低仰角、网格间隔和首尾空档策略。四张统计卡片展示网格数、曾覆盖面积占比、平均覆盖率及最长空档。热力图支持切换时长占比 / 最长空档、悬停、点击或方向键选点、区间列表、场景时刻定位及 PNG/剪贴板；表格和曲线支持既有格式与 CSV 导出。窄窗口保留设置与结果切换，变化不触发重新计算。

Python 示例见 [coverage.py](../../examples/python/coverage.py)：`analysis.report(ob.ReportKind.COVERAGE_GRID, objects=[satellite], coverage=grid, step=u.s(60))`。`CoverageGrid` 是可编辑的 SI 配置；返回的 `coverage_statistics.points` 保留每点位置、面积、合并区间与统计，模板转换不会重算轨道。ALL 模式不适用于覆盖资产。

项目格式 v46 / RPTS7 保存全部覆盖参数，包括非活动草稿；只接受当前格式，旧版本明确拒绝。结果不写入项目，模板保存查询输入。暂不包含地形/折射、自定义多边形、自适应网格、概率覆盖、多重同时覆盖、重访百分位、通信链路及区域传感器规划。
