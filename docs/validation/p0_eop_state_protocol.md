# EOP 与完整状态转换验收协议

C04 与完整状态变换使用以下固定输入约定与数值门槛；它们检验接口/数值实现，不作为真实轨道预报精度承诺。

- IERS 20 C04 0h UTC、dX/dY 格式，以原始下载和截取快照的 SHA256、来源、日期窗口固定数据。导入只读取本地文件，不自动更新或外推；缺日、重复日、损坏值、日期/MJD 不一致或散列不匹配均报错。
- 插值以 TAI 秒为自变量，先把每个 UTC 节点的 DUT1 转为 UT1−TAI，再进行三次 Hermite 插值。UT1 斜率由 LOD 得到，xp/yp 使用源数据的日变化率；dX/dY 节点斜率由相邻数据估计。须覆盖 2016 正闰秒，输入时间步长包含真实的第 86401 秒。
- 在原始节点核对单位转换：UT1−TAI 绝对误差 ≤1e-12 s，角度 ≤1e-18 rad。以独立人工多项式验证插值值及导数，不用被测实现生成黄金值。
- 参考系采用 IAU 2006/2000A 与显式 dX/dY。旋转矩阵对同源官方参考的元素误差 ≤1e-12；独立实现交叉对照需说明实际模型、数据和误差来源，不能把 SOFA/ERFA 互比标为独立。
- Orekit 独立校验在首次执行前固定元素容限为 2e-11，速度分量容限为 2e-5 m/s；参考导数使用 2 秒、4 秒步长五点差分，两步长结果差异亦须 ≤2e-5 m/s。两端采用同一请求点的 EOP 局部切线，不额外查询覆盖外数据。
- 完整状态使用 `r'=Rr`、`v'=Rv+R_dot*r`。速度对平滑解析轨迹位置的五点差分误差 ≤2e-5 m/s（半径不超过 42,164 km，速度不超过 8 km/s）；正逆往返位置误差 ≤5e-8 m，速度 ≤5e-10 m/s。另用固定地面点验证约 465 m/s 的地球自转速度量级和方向。
- 变换必须拒绝错误历元、原点、参考系和非有限状态；关闭第三方 Provider 的构建仍可单独编译 Core。验证 C++、安装后的 SDK、Python wheel 与移动后的数据目录。

详细实测、差异及未通过项写入当次本地报告，不通过修改容限掩盖实现错误。日内潮汐/海潮改正未包含时必须在模型元信息中注明，不能宣称完整 IERS 高精度实现。
