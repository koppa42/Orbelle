# CSPICE 接入验收协议

实现前固定以下约束和容限，验证范围是数据/时间/星历封装，不是实际天体预测精度。

- 固定 CSPICE N0067 与依赖基线；所有调用（包含加载、清理、错误状态处理）统一串行。多个只读快照可交替查询，失败后必须可继续查询正常快照。并发结果与逐个串行查询一致。
- 显式指定本地清单与工作目录。记录内核加载顺序、每个文件的 SHA256、来源、清单散列与允许的 TAI 历元窗口。验证后的字节复制为 Provider 拥有的运行副本，查询不继续读取原始数据目录；副本销毁前关闭 CSPICE。禁止隐式下载、替代数据、元内核递归加载或范围外外推。
- 仅查询几何状态（`abcorr=NONE`），目标/观测者使用显式 NAIF 编号，坐标轴标为 `SPICE_J2000`，SI 位置/速度，速度明确按 TDB 秒求导；不隐式转为 GCRF 或 TAI 导数。
- Epoch 的 TAI 零点保持不变；通过 `unitim` 转换 TAI/TDB，不使用 SPICE 的 UTC 表替代既有 IERS UTC 路线。ET 是双精度 TDB 秒，2000 零点附近与 2016/2017 验收窗口的往返允许 1 µs 量化误差；输入 Epoch 本身仍保留纳秒。该门槛不适用于全 int64 范围；极端整数另按 `max(1 µs, 4 ULP(ET))` 检查算术安全与往返，不承诺远期模型物理精度。
- 用人工多项式 SPK 验证位置误差 ≤1e-6 m、速度 ≤1e-9 m/s；真实内核与独立 jplephem Type 2 读取器比较，位置 ≤1e-3 m、速度 ≤1e-7 m/s。独立比较使用相同 TDB 输入，不把它当成独立 TDB 模型验证。
- TDB−TT 用 ERFA 完整地心模型另行对比；CSPICE 简化模型在测试日期的差异须 ≤50 µs，明确这项容限比浮点时间往返容限宽，不能据此声称纳秒级时间模型精度。
- 数据损坏/缺失、路径逃逸、错误内核类型、清单越界、实际 SPK 覆盖不足均明确失败。测试跨数据集优先级、错误恢复、多线程交替、源文件移动/修改后的所有权，C++ SDK 和安装后的独立 wheel 都实际运行。
