# HPOP 联合协方差验证

对象是[初始 6×6 状态矩阵与 D/K 考虑参数的联合传播](../architecture/hpop_covariance.md)。使用原有 Orekit 全弧 STM / 敏感度作为独立动力学输入，再以独立矩阵库和高精度直接乘法核对协方差。没有调用 OrbitForge 生成真值，也没有 STK 实机验收结果。

## 固定参考与复现

生成器为 `tools/validation/hpop_covariance_reference.py`，依赖固定 NumPy 2.3.3、SciPy 1.16.3、mpmath 1.3.0。输入固定 [Orekit / Hipparchus 变分参考](hpop_variational_protocol.md)，并核验其 SHA-256；需要原始力模型输入和全部物理参数时以该协议为准。

```text
python tools/validation/hpop_covariance_reference.py <输出文件>
```

输出两次必须字节一致，才更新 `tests/reference/propagators/hpop_covariance.txt`。72 组为 36 条独立轨迹各两套矩阵：无参数、D、K、D+K 轮换，覆盖对角与完整状态／参数交叉矩阵、有符号 D/K 互协方差、名义正／零／负系数、独立 2×0 变分引力以及双锥食影。

标准差基准为位置 `(1000,2000,700)` m、速度 `(0.2,0.5,0.7)` m/s、D/K `(0.004,0.003)` m²/kg。第二套将状态尺度乘 0.01、参数尺度乘 10，并以固定随机种子 20261018 构造完整相关矩阵。先以 SciPy LAPACK Cholesky 核对活动联合矩阵；NumPy 直接执行 `F P0 Fᵀ` 和三项分解。另用 mpmath 80/100 位十进制精度计算相同双精度输入的直接矩阵乘法，两档结果舍入 double 必须完全一致；固定文件保存该高精度结果。NumPy 与它的分块最大范数相对差须小于 3e−14，输出也经 SciPy 正定检查。

固定文件 ASCII / LF SHA-256 为 `641f42c6f6857992c46cf572ebc102a996f6383c24f62dc00903f3846c8dd6c6`；NumPy 对高精度的最大分块相对差为 `3.891e−16`。

参考文件使用固定 8×8 槽位 `(r,v,D,K)`；未选择的参数整行整列填零，不将这些空槽纳入活动矩阵正定校验。生成器附带元数据和矩阵顺序说明。

## 计算与接口验收

`HpopCovariance.JointPropagationMatchesIndependentOrekitNumpyAndHighPrecision` 先将相同 Orekit STM / S 交给生产矩阵传输，分离矩阵算法误差；再实际调用完整 HPOP 协方差传播，覆盖五种积分器、VOP、普通与 Sundman 时间。各条轨迹的力、资源、阶次与既有独立参考对齐。

联合矩阵按 `|ΔPij| / sqrt(Pii Pjj)` 检查，分别限 3e−14（代数）与 3e−9（完整传播）。分解项按速度维乘 1000 s 的物理尺度，比较块最大范数；代数限 3e−14，传播初始状态项限 3e−9，较小的参数及交叉项限 2e−7，保持与既有 D/K 敏感度验收相称。不能用占优势的初始位置方差掩盖参数项错误。

当前 MSVC 的 72 组最大相关尺度误差为 `7.920e−16`（代数）、`1.519e−10`（完整传播）；参数及交叉分项最大相对差为 `1.555e−9`、`9.982e−10`。这些是对齐输入的数值算法差异，不是实际轨道精度。

另检查：

- 单独合法二元相关性不能替代联合正定性；非法零／负／NaN 方差、非对称、过大的交叉项和未选择参数的互协方差必须拒绝。
- 物理对角从 1e−280 到 1e280 的混合单位矩阵；相关尺度的舍入容许和输出精确对称。
- 强抵消的解析案例：初始状态与参数相关系数趋近 −1，总量通过平方根计算，交叉分项保持负值，不以裁剪或额外噪声掩盖。极端 Jacobian 仅是浮点范围测试，不声称实际轨道适用性。
- 连续两段的联合传播与复合 Φ/S 相等；参数方差及 D/K 互协方差逐位保持。奇异、非有限及溢出结果拒绝；取消、重试和回调期间输入捕获不发布部分输出。
- 安装 Python 对独立 Orekit 开普勒参考、结果所有权、并发、验证和取消进行测试；真实 UTC/EOP/DE440s 的零 Cd/Cr 阻力与光压验证参数敏感度仍产生协方差贡献及分段复合。
- 安装 SDK 消费端调用带卫星视太阳的完整协方差 API，检查 K 项贡献、交叉项与参数方差。

逐次命令、工具链、散列和误差最大值保存于 `out/validation/`。项目格式、桌面、帧转换、FG 表示、协方差插值与跨机动传播在相应功能接入时另行验收。
